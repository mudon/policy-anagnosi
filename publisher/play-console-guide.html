1. What to deploy

Upload the contents of public/ to your static host, preserving its paths. There is no build step, backend, external font, tracking code or public form. The six public HTML pages work without JavaScript.

PagePurpose
index.htmlPublic Anagnosi help and policy hub.
privacy-policy.htmlUse the hosted, public HTTPS URL in Play Console's privacy-policy field. Also add the policy/link inside the app.
terms-of-use.htmlYour user agreement. This is not Google's Developer Distribution Agreement, which you handle in Play Console.
delete-data.htmlLocal deletion instructions and support-data requests; no imaginary account-deletion service.
support.htmlPublic support URL and contact details.
third-party-notices.htmlTranslation disclaimer and component/service credits. Release-specific licence notices still belong in the distributed app.

The publisher is mudon; the contact is muhammadhazim57@gmail.com. Use consistent app/developer identification in your listing. Update the effective date if you publish materially later or change the policy. Keep the privacy URL accessible without login, geographic blocking or a PDF viewer. These are authored documents for your actual app, not a certification of legal compliance or Play approval.

If your host adds analytics, cookies, forms or extra logging, update the website section of the Privacy Policy. Adopt the stated support practice: normally remove resolved support email within 12 months, retaining longer only for the specified justified reasons.

Update policy deployment

Deploy public/update-policy.json with the HTML pages. It targets latest app version 0.4.2+6 and keeps minimum code 4. Read the update release guide for the default GitHub Pages address, optional versus required releases, offline behaviour, recovery and testing.

App-access note for reviewers

No login, account, subscription or special access code is needed. Library starts empty. Tap Import a book or the + button and select your own PDF or DRM-free EPUB document. No sample books are bundled. Long-press selectable text for Highlight, colour choices, Translate, Copy, Add note and Read aloud. Finish Move/Resize with Done before zooming or selecting. Read aloud requires an installed offline Android voice; translation downloads missing models on first use, over Wi-Fi by default. No provider account or API key is needed from the reviewer.

3. Data safety worksheet

Do not answer “No data collected” just because books stay local. The integrated ML Kit translation SDK reports technical/usage information. On-device library processing and SDK telemetry need different answers. The classifications here are a source-and-provider-documentation assessment; the final release and all active versions must match.

Questions that need a release check

  • Shared: transferring SDK data to Google must be assessed under Play's sharing definition and applicable exceptions. Google's statement about no onward transfer does not alone establish that your app-to-Google transfer is exempt. Only choose “not shared” where the documented service-provider or other exception actually fits; otherwise disclose the transfer.
  • Required versus optional: the app has no universal telemetry opt-out. Use “required” as the conservative working answer for SDK telemetry unless you prove every user can avoid or control that collection. An optional Translate button alone is not proof that SDK startup or diagnostics are optional.
  • Ephemeral: do not mark SDK metrics ephemeral without evidence that they meet the relevant memory-only/real-time condition. Local processing is a different issue.
  • Encrypted in transit: Google's ML Kit disclosure says its reported data uses HTTPS. Verify every endpoint and SDK in the final release before saying all applicable transmissions are encrypted.
  • Deletion requests: the public page provides local deletion and support-email requests. It is not proof that Google-managed telemetry can be deleted by mudon. Verify the coverage needed for the exact deletion answer shown in your Console.

Speech, clipboard and email

Read aloud passes document text to a separately installed speech engine, even when the voice is offline. Copying/pasting can move text to another app. Check Play's user-initiated-transfer exception and the clarity of the user-facing explanation; do not equate all on-device inter-app transfers with no sharing. An external email support channel is not an in-app account or an automatic document upload. If you later add a support form or send diagnostics from the app, reassess those fields.

What to verify in the AAB

Inspect the resolved release dependencies and merged manifest, then observe a fresh install at launch, before translation, during the first model download and after models exist. Confirm SDK startup/telemetry, destinations, data fields, required/optional behaviour, voice behaviour and deletion limits. The source declares com.google.mlkit:translate:17.0.3, whose translation stack can use Firebase Remote Config and Firebase Installations. The provider's disclosure describes its latest SDKs, so compare the exact versions actually shipped.

Version-policy host and Google Play update processing

The app now makes HTTPS requests for update-policy.json at launch/resume. The host receives ordinary connection details (including IP address, time, path and network headers). The app adds no document text, annotations, installed-version identifier or user identifier to that request. Assess the deployed host's actual log fields/retention and the matching Play Data safety data types, purposes and sharing exceptions; do not automatically mark the request as exempt or ephemeral. The operational purpose is app functionality. If a host derives or retains approximate location or other data, assess those fields too.

Google's Play update documentation lists device metadata, application version and installed modules/asset packs used for update availability/size. Google Play runs its own processes under Play terms. This is separate from ML Kit's analytics telemetry. Review the exact update SDK and final app declarations rather than labelling all update data as analytics or assuming these fields imply Advertising ID collection.

Repeat network observation at launch/resume, while checking/updating, and with the required policy cached. The cached policy/verified floor stays in private app preferences. The public Privacy Policy, Terms, support and notices now describe this feature.

4. Remaining app-release work

Version 0.4.1+5 adds user-granted SCHEDULE_EXACT_ALARM for reading/rest timers, with an approximate fallback when declined. It does not declare USE_EXACT_ALARM. Keep the public permission explanation in the Privacy Policy and test permission grant/denial, screen-off timers and short repeats on supported devices.

Checkboxes are only a local reading aid and are not saved or sent anywhere. Terms, publisher practices and release declarations should be reviewed for the countries in which you distribute the app.

Update release check: deploy the JSON, verify the app URL/package ID, and test an actual old-to-new release through Google Play. Read Updates & version policy. The compiled personal APK does not prove Play eligibility, production signing or real Play installation.
